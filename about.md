# About

Tallgrass Code is a public site for practical NEC code articles, electrical education, Electric Utility watthour metering and transformer conection,Electric calculations for the exam and in the field, and more.

The purpose of this site is to help explain electrical code topics in plain language while still referencing the adopted code, local amendments, and authority having jurisdiction.

## Disclaimer

Information on this site is for education and discussion. Always verify requirements with the adopted NEC edition, local amendments, manufacturer instructions, listing requirements, and the AHJ.
